# 🩺 Disease Prediction System using Machine Learning

## 📌 Project Overview

This project is a machine learning application that predicts whether a patient is likely to have diabetes based on various medical measurements. It uses the **Pima Indians Diabetes Dataset** and a **Logistic Regression** model from Scikit-learn.

The objective of this project is to demonstrate the complete machine learning workflow, including data preprocessing, exploratory data analysis, model training, evaluation, and prediction.

---

## 🎯 Objectives

* Understand the complete machine learning pipeline.
* Perform exploratory data analysis (EDA).
* Train a Logistic Regression model for binary classification.
* Evaluate model performance using standard metrics.
* Predict diabetes for new patient data.
* Build a strong foundation for future healthcare AI projects.

## 📊 Dataset

This project uses the **Pima Indians Diabetes Dataset**, which contains medical information such as:

* Pregnancies
* Glucose Level
* Blood Pressure
* Skin Thickness
* Insulin
* Body Mass Index (BMI)
* Diabetes Pedigree Function
* Age

### Target Variable

* **0** → No Diabetes
* **1** → Diabetes

---

## ⚙️ Machine Learning Workflow

1. Import required libraries
2. Load the dataset
3. Explore and analyze the data
4. Visualize feature relationships
5. Split the data into training and testing sets
6. Standardize the features using `StandardScaler`
7. Train a Logistic Regression model
8. Evaluate model accuracy
9. Predict diabetes for new patient data
